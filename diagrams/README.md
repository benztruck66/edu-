# Draw.io Диаграмууд

Энэ хавтас нь таны education portal төслийн үйл ажиллагааны диаграмуудыг агуулна.

## Файлууд

### Бүрэн үйл ажиллагааны диаграм
**complete-workflow.drawio** - Бүх үйл явцыг нэгтгэсэн swimlane диаграм
- Нэвтрэх үйл явц
- Хайлтын үйл явц
- Хөтөлбөр зөвлөх үйл явц
- Хэрэглэгч vs Систем swimlane-ууд

## Хэрхэн ашиглах

### Draw.io онлайн

1. https://app.diagrams.net/ (эсвэл draw.io) руу очно уу
2. **File → Open from → Device** сонгоно уу
3. `.drawio` файлыг сонгоно уу
4. Диаграмыг засварлаж, хадгалаарай

### Draw.io Desktop

1. Draw.io desktop програмыг суулгана уу
2. Файлыг нээнэ уу
3. Засварлаж, хадгална уу

### Visual Studio Code

1. VSCode-д "Draw.io Integration" extension суулгана уу
2. `.drawio` файлыг нээнэ уу
3. Шууд засварлаж болно

## Диаграмын элементүүд

- **Ногоон тойрог** - Эхлэл/Төгсгөл
- **Цэнхэр бөөрөнхий тэгш өнцөгт** - Үйл ажиллагаа
- **Шар ромб** - Шийдвэр/Нөхцөл
- **Улаан бөөрөнхий тэгш өнцөгт** - Алдааны боловсруулалт
- **Сум** - Үйл явцын чиглэл

## Засварлах

Диаграмуудыг draw.io-д нээж, хүссэнээрээ засварлаж болно:
- Элементүүд нэмэх/устгах
- Байршлыг өөрчлөх
- Өнгө, хэмжээг өөрчлөх
- Текст засах
