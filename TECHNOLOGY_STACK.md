# Технологийн Стек (Technology Stack)

## Ерөнхий мэдээлэл

Энэ төсөл нь **Next.js** framework дээр суурилсан **React** веб аппликейшн юм.

## Ашигласан технологи, програм хангамж

### Frontend Framework
- **Next.js 16.0.0** - React-д суурилсан production-ready framework
- **React 19.2.0** - JavaScript UI library
- **TypeScript 5** - Type-safe JavaScript

### Стиль, Дизайн
- **Tailwind CSS 4** - Utility-first CSS framework
- **PostCSS** - CSS processing tool

### Хөгжүүлэлтийн хэрэгслүүд
- **Node.js 18+** - JavaScript runtime
- **npm** - Package manager
- **ESLint** - Code linting tool

### Хадгалах
- **localStorage** - Браузер дээрх local storage (одоогийн байдлаар)

### Хөгжүүлэлтийн орчин
- **Visual Studio Code** (VSCode) - Code editor
- **Git** - Version control

## тайлбар

"Энэ системийг **Next.js** framework дээр **React** болон **TypeScript** ашиглан хөгжүүлсэн. **Tailwind CSS** ашиглан дизайн хийсэн. **Node.js** runtime дээр ажилладаг веб аппликейшн юм."

## Товч тайлбар

- **Next.js** - React-д суурилсан веб хөгжүүлэлтийн framework
- **React** - Facebook-ийн хөгжүүлсэн JavaScript library
- **TypeScript** - Microsoft-ийн хөгжүүлсэн type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **Node.js** - JavaScript runtime environment

## Суулгах, ажиллуулах

```bash
# Dependencies суулгах
npm install

# Development server эхлүүлэх
npm run dev

# Production build хийх
npm run build

# Production server эхлүүлэх
npm start
```
