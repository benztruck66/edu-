## Хэрхэн нэрлэх:

### Windows дээр:
1. `public/logos/` хавтас руу орох
2. Файлыг right-click хийж "Rename" сонгох
3. Зөв нэрийг бичих (жишээ: `num.png`)
4. `.png` өргөтгөл нь нэг удаа л байх ёстой!

### Эсвэл PowerShell ашиглах:
```powershell
cd public\logos
Rename-Item "`num.png`.png" "num.png"
Rename-Item "`must.png`.png" "must.png"
```
